# Animal Crossing Memory Card Game 🍃

A fun memory challenge featuring Animal Crossing cat villagers! Test your memory by clicking each villager card exactly once. The cards shuffle after every click - can you keep track of who you've already selected?

[Play the game here](https://ac-memo-game.vercel.app/)

## How to Play 🎮
1. Click any villager card to earn a point
2. Remember which villagers you've clicked
3. Cards shuffle after each turn
4. Don't click the same villager twice!
5. Win by clicking all villagers once

### Card Feedback
- 🟢 Green border = Correct (new card picked)
- 🔴 Red border = Wrong (already picked this card)

## Features ⭐
* Real-time score tracking
* High score saves between sessions
* Background music toggle
* Responsive design for all devices
* Flip and hover animations

## Tech Stack 💻
* React & TypeScript
* Tailwind CSS for styling
* Vite for development
* localStorage for high score persistence
* [Nookipedia API](https://api.nookipedia.com/) for villager data
* Vitest & React Testing Library for testing
